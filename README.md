**Ozon Parser** (в браузере называется Ozon ROI Hunter) — парсер Ozon в виде расширения для Chrome. Он собирает товары со страниц Озона: каталога, поиска и акций. Главная задача — найти товары с самой выгодной акцией «Баллы за отзыв»: сколько баллов вернётся относительно цены товара.

Сделано на заказ, по требованиям заказчика.

## Что умеет

- **Ручной поиск.** На открытой странице Ozon (каталог, поиск, страница акции) проходит заданное число страниц и отбирает товары, где баллов за отзыв не меньше порога.
- **ROI.** Для каждого товара считает выгоду: `баллы / цена × 100 %`. Результаты сразу отсортированы по ней.
- **Таблица результатов.** Карточки с фото, ценой, баллами и ROI. Сортировка по ROI, баллам и цене, клик ведёт на товар.
- **Экспорт в Excel.** CSV с разделителем `;` и BOM, чтобы кириллица открывалась в Excel без танцев.
- **Фоновый монитор.** Раз в N минут проверяет страницу акции. Новые товары выше порога копятся в отдельной таблице, а их число видно на значке расширения.

## Как работает

Товары берутся не из вёрстки, а из JSON, которым Ozon сам наполняет витрину (`/api/entrypoint-api.bx/page/json/v2`). Запросы идут из открытой вкладки Ozon с её же сессией, поэтому сайт не отвечает 403.

В ответе ищутся карточки со ссылкой на `/product/`, а в них — «N баллов за отзыв» и цена в рублях. Название и картинка достаются обходом вложенных данных карточки, следующая страница — по полю `nextPage`.

Чтобы не нагружать сайт, между страницами стоит пауза 1–2 секунды. Монитор срабатывает с разбросом ±10 минут от заданного интервала и не чаще раза в 5 минут.

| Файл | Что делает |
| --- | --- |
| `manifest.json` | Manifest V3: права, service worker, content script для `ozon.ru` |
| `content.js` | Запросы к API витрины, разбор ответа, ручной поиск и фоновая проверка |
| `background.js` | Состояние поиска, расписание монитора (`chrome.alarms`), счётчик на значке |
| `popup.html`, `popup.js` | Окно расширения: настройки поиска и монитора |
| `results.html`, `results.js` | Таблица результатов, сортировка, экспорт CSV |

## Установка

1. Скачать репозиторий (Code → Download ZIP) и распаковать.
2. Открыть `chrome://extensions` и включить «Режим разработчика».
3. Нажать «Загрузить распакованное расширение» и выбрать папку с `manifest.json`.

## Использование

1. Открыть на Ozon нужную страницу: каталог, поиск или акцию «Баллы за отзыв».
2. В окне расширения указать, сколько страниц пройти и минимум баллов, и нажать «Начать ручной парсинг».
3. Когда поиск закончится, таблица результатов откроется в новой вкладке.

Для монитора нужно указать ссылку на акцию, порог баллов и интервал, затем нажать «Включить авто-поиск». Пока монитор работает, должна быть открыта хотя бы одна вкладка Ozon.

## Ограничения

- Разбор опирается на текущий формат ответа Ozon. Если сайт поменяет структуру данных или подписи («баллов за отзыв»), поиск придётся подправить.
- Настройки монитора хранятся в памяти service worker. После перезапуска браузера монитор нужно включить заново.
